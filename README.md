# AWS Cost Reduction Project - Pharmaceutical Industry

Projeto desenvolvido durante a trilha **Java e Cloud Native - Accenture / DIO**.

## 📌 Objetivo

Este projeto apresenta uma proposta de implementação de serviços da AWS para reduzir custos operacionais de infraestrutura em uma empresa farmacêutica.

A proposta considera a adoção de serviços gerenciados da AWS para melhorar:

- Escalabilidade
- Disponibilidade
- Segurança
- Redução de custos

## 🏗️ Serviços AWS Propostos

- Amazon S3
- Amazon RDS
- AWS Lambda
